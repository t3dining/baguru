# 管理画面の受け口を置いて、GitHub につなぐ（ホームページを公開するとき）

> [!warning] ★会社のアカウントで作る
> Google も GitHub も **会社のアカウント**（Google はオレンジの T の Chrome）で作ります。個人のアカウントには作りません。
> GitHub の鍵と合言葉は、このファイルにも、ほかのどこにも書きません。

ホームページを会社の GitHub（`t3dining/baguru`）に置いて、GitHub Pages を「GitHub Actions」で出すようにしたあとで行います（2026-11-04 に置いた。Coming soon の期間）。
Claude が1画面ずつ案内します。`コード.gs` と `画面.html` の中身は、Claude が Mac のクリップボードに入れるので、貼るだけでよい。

## 1. GitHub の鍵を作る（ご自身で）

1. 会社の GitHub で、右上のアイコン →「Settings」→ 左の下の「Developer settings」→「Personal access tokens」→「Fine-grained tokens」→「Generate new token」
2. 名前：`バグる ホームページの管理`。期限は選べるいちばん長いもの（切れたら作り直して、3 で入れ直す）
3. Resource owner：`t3dining`。Repository access：「Only select repositories」で `baguru` だけ
4. Permissions：**Contents** を「Read and write」、**Actions** を「Read-only」
5. 「Generate token」で出た鍵を写す（★この画面を閉じると二度と見えない。チャットにも貼らない）

## 2. Google に受け口を置く

1. 会社の Google で https://script.google.com/ →「新しいプロジェクト」。名前は `バグる ホームページの管理`
2. `コード.gs` の中身を全部写して貼り、保存
   - 左の「ファイル」の「＋」→「HTML」→ 名前を `画面` にする（`.html` は自動で付く）。中身を消して、`画面.html` の中身を全部写して貼り、保存
   - `画面.html` は `作る.py` が作る。貼る前に `python3 作る.py` を動かしておく
3. 左の歯車（プロジェクトの設定）→ いちばん下の「スクリプト プロパティ」→「スクリプト プロパティを追加」
   - プロパティ：`GITHUB_TOKEN`、値：1 で写した鍵 →「スクリプト プロパティを保存」
4. エディタにもどり、上で `setup` を選んで「実行」→ 許可の画面で会社のアカウントを選んで許可
5. 下の「実行ログ」に「GitHub につながりました（書き込めます）」と「データ/menu.json を読めました」が出れば成功。管理画面の合言葉もここに出る（★チャットに貼らない）

## 3. ウェブアプリにする

1. 右上の「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
2. 次のユーザーとして実行：**自分**。アクセスできるユーザー：**全員**
3. 「デプロイ」→ 出たウェブアプリの URL が、**管理画面のアドレス**になる
   - お店の人のスマホ・パソコンでこのアドレスを開き、ブックマークするか、ホーム画面に追加する（ホームページには載せない）
   - アドレスは、使う人にだけ知らせる。知られても、合言葉がないと何も変えられない
   - 開くと、いちばん上に Google の「このアプリケーションは Google ではなく、別のユーザーによって作成されました」という帯が出る（Google が出すもので、消せない）
4. 合言葉（2-5 のログ）を入れて入り、お知らせかメニューを1つ直して保存 → 2〜3分でホームページに出ることを確かめる

## コードを新しくしたとき

`python3 作る.py` →「コード.gs」と「画面」を貼り直して保存 →「デプロイ」→「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」→「デプロイ」（URL は変わらない）

## 困ったとき

- 開くと Google ドライブの「現在、ファイルを開くことができません」が出る：その Chrome で、Google のアカウントにいくつもログインしているため（2026-11-04、個人の Chrome の バグる Owner から開いて出た。会社の Chrome と、個人の Chrome のシークレットウィンドウでは開けた）。会社の Chrome（オレンジの T）か、スマホのバグる Owner から開く

- 「GitHub に書き込めませんでした」：鍵の期限が切れたか、権限が足りない。1 で作り直して、2-3 で入れ直す
- 合言葉を変えたい：スクリプト プロパティの `PIN` の値を、自分で決めた合言葉に書き換えて保存する（すぐ変わる。デプロイし直さなくてよい）。`PIN` を消して `setup` を実行すると、ばらばらの文字の新しい合言葉ができる（ログに出る）。変えたあとは、どの端末も入り直す
- 試し用（この Mac の `管理/にせの合言葉.txt`）も、ファイルを書き換えて保存すればすぐ変わる
- 何度もまちがえて入れない：30分待つ（スクリプト プロパティの `LOCK_UNTIL` を消すとすぐ入れる）
