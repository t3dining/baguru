# ホームページの管理画面（2026-10-30 作った）

お店の人が、スマホやパソコンから **お知らせ** と **メニュー（写真・名前・値段・説明・売り切れ）** と **ページの文章** を変えるための画面です。
デザイン（並び・色・字の大きさ）と、文を足す・消すのはここではしません。Claude に頼みます（2026-11-02 から、文と値段はお店の人が直し、Claude はデザインとしくみだけ）。

```
 管理画面（受け口のアドレスを開くと出る・合言葉で入る。ホームページには置かない）
     │ 保存
     ▼
 受け口（会社の Google のウェブアプリ・管理/受け口/コード.gs と 画面.html）── 合言葉を確かめる
     │ GitHub の鍵（受け口の中だけに置く）で書き込む
     ▼
 会社の GitHub のホームページの置き場所（データ/menu.json・news.json・texts.json・データ/写真/）
     │ 変更が入ると .github/workflows/publish.yml が動く
     ▼
 作る.py でページを作り直して、GitHub Pages に公開（2〜3分）
```

## ファイル

| ファイル | 中身 |

| `受け口/画面.html` | Google に貼る管理画面の1枚。`作る.py` が `画面/` の3つをまとめて作る（直接直さない） |
| `受け口/コード.gs` | 本物の受け口（会社の Google に置く）。アドレスを開くと `画面.html` を出し、管理画面からの頼みごと（`api`）に答える |
| `受け口/受け口の作りかた.md` | 受け口を置いて GitHub につなぐ手順（公開のとき） |
| `にせの受け口.py` | この Mac の中で試すための受け口。GitHub の代わりに `../データ/` に書き、`作る.py` で作り直す |
| `../管理画面を試す.command` | ダブルクリックで、にせの受け口を動かして管理画面を開く（http://localhost:8134/kanri/。`画面/` をそのまま配る） |
| `../データ/menu.json`・`news.json` | メニューとお知らせ。ページの `{{list:…}}`・`{{news:…}}` の行に入る（`作る.py` の `put_data`） |
| `../データ/texts.json` | ページの文章（ページ → 見出しごとのまとまり → 文）。ページの `{{t:キー}}` に入る（`作る.py` の `put_texts`）。並びは `../道具/文章を分ける.py` が作る |
| `../データ/写真/` | 管理画面で入れた写真（`u-日付-時刻-○○○○.jpg`）。組み立てるとき `公開用/img/` に写る |

## 決まり

- ★**メニューとお知らせを Claude が直すときも、`データ/menu.json`・`news.json` を直す**（`ページ/menu.html` などには `{{list:…}}` の行しかない）。見出し・説明文・注意書き（「価格は全て税込です」など）は、これまでどおり `ページ/` にある
- 群（「炭焼ハンバーグ」「サイドメニュー」など）を足す・消す・並べ替えるのは Claude の仕事（`menu.json` と `ページ/` の両方を直す）。管理画面からは、群の中の品だけを変えられる（受け口が群の形を守る）
- 品の形（形ごとに入れられるもの・長さの上限）は、`kanri.js` の `FIELDS`、`コード.gs` の `TYPE_KEYS`・`cleanItem_`、`にせの受け口.py` の `TYPE_KEYS`・`clean_item`、`作る.py` の `group_lines` でそろえる。1つを変えたら全部直す
- 品の `status`：なし＝ふつう、`soldout`＝売り切れ（名前の横に印・写真を灰色に）、`paused`＝しばらくお休み（ページに出さない）
- 文章は、管理画面からは文の中身だけ変えられる（受け口がページ・まとまり・キー・並びを守る。空にはできない。1文1000字まで）。改行は `<br>`、`**…**` は太字になる
- 「ページで直す」で文を入れかえる形（`../公開用/js/edit.js` の render）と、直す欄の形（`画面/kanri.js` の mirrorDraw・phrases）は、`作る.py` の rich・add_wbr・phrases と同じにしておく。1つを変えたら、全部直す
- 改行できない文（ページの題 `title`・検索結果の説明 `desc`・ページの上の大きな見出し `hero`・その下の字 `herosub`）と字数の上限は、`kanri.js`・`コード.gs`・`にせの受け口.py` の `ONE_LINE` でそろえる
- ★ページの並びを直して文を足した・消したら、`python3 道具/文章を分ける.py` を動かす（消えた文は texts.json からも消える。前の形は GitHub の履歴に残る）
- 写真は、管理画面の中で群の形（`menu.json` の `size`）に切り取ってから送る。古い写真は消さない（前に戻せるように）
- ★合言葉と GitHub の鍵は、ファイルにもノートにも書かない。受け口の「スクリプト プロパティ」だけに置く
- `管理/にせのデータ/` と `管理/にせの合言葉.txt` は公開しない（`.gitignore`）
- ★管理画面はホームページ（`公開用/`）に置かない。開けるのは受け口のアドレスだけ。アドレスはホームページにもノートにも書かない（秘密ではないが、知らせる人を絞る）
- `画面/` を直したら `python3 作る.py` で `受け口/画面.html` を作り直し、Google に貼り直す（`受け口/受け口の作りかた.md` の「コードを新しくしたとき」）

## この Mac で試す

1. `管理画面を試す.command` をダブルクリック（ブラウザで管理画面が開く。合言葉は、開いた窓に出る）
2. ★ここで保存すると、この Mac のホームページのデータが本当に変わる。試したあとは「前に戻す」で戻せる
   - ★「前に戻す」は、メニュー・お知らせ・文章をまとめて、そのときの形に戻す（そのあとに Claude がファイルで直したメニューも戻ってしまう）。文章ができる前（2026-11-02 より前）の形に戻すと、文章だけは今のまま
3. ホームページの見え方は、同じアドレスの `http://localhost:8134/` で見られる
