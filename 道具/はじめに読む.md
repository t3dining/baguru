# 道具（作る.py が使うもの）

| ファイル | 何か |
|---|---|
| `budoux_ja.json` | BudouX（Google）の日本語のモデル。文を「文節」に分けるのに使う。PyPI の budoux 0.6.4 から取り出したもの |
| `BudouX_LICENSE.txt` | BudouX のライセンス（Apache License 2.0）。モデルを使うときは一緒に置いておく |

`作る.py` は、ページの本文の日本語に、文節の切れ目ごとに `<wbr>`（ここで改行してよい、という印）を入れます。
CSS の `word-break: keep-all` と合わせて、**文の途中では改行せず、改行するなら文節の切れ目で**改行されます。

★このフォルダのファイルは直さない（モデルを新しくするときは、budoux の新しい版から取り直す）。
